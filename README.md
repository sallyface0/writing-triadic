# Writing Triadic — 自我进化的三角色协作写作 Skill

> 写作不是一次 AI 生成任务。它需要**深度理解意图**、**精准执行**、**真实读者反馈**。
> v2.1 新增「自我进化引擎」——越用越懂你，每次写作都在变聪明。

## ✨ 核心理念

传统的 AI 写作就是"你说一句，它写一段"。Writing Triadic 把写作拆成三个角色 + 一个进化引擎：

| 角色 | 中文名 | 职责 |
|---|---|---|
| 🧠 **Creator** | 创作者 / 内容架构师 | 深层挖掘用户意图（4问/轮），自动匹配最佳写作模板，驱动进化引擎 |
| ✍️ **Executor** | 执行者 / 精密写手 | 按规则产出 ≥2 版有本质差异的初稿 |
| 👁️ **Reader** | 读者 / 灵魂受众 | 代入目标读者身份，加权六维评分，选出最佳版本 |
| 🧬 **Evolution Analyst** | 进化分析师 | 每次写作后自动提炼偏好，按写作类型标签归档 |

## 🆕 v2.1 核心升级：自我进化引擎

### 写作类型 × 维度矩阵记忆

```
[商业文案] 宣传语 → "不要硬推，太像广告" → 语调偏软，禁用促销词
[博客文章] 技术分享 → "代码块太多重点不突出" → 3-4技巧上限，代码精简
[随笔/散文] ... → ...
```

**不同写作类型的偏好相互隔离，不会串味。** 写宣传语学到的规则不会错误应用到技术博客上。

### 三层偏好注入

```
全局偏好 (跨类型通用)
  ↓
当前写作类型精确匹配 ([博客文章] 专属)
  ↓
相邻类型参考 ([技术文档] 查不到时参考 [博客文章])
```

### 即时纠错 + 自动记忆

你说"太啰嗦了"→ 立即修改 + 自动记入 MEMORY.md。下次自动规避。**用一次，聪明一次。**

## 🚀 快速开始

### 安装

```bash
openclaw skills install writing-triadic
```

### 使用

直接说你想写什么：

- "帮我写一篇关于 AI 的博客"
- "写个产品文案"
- "帮我写个工作总结"
- "写个小说开头，科幻的"

### 工作流程

```
用户提需求
    ↓
Phase 0: 读取你的风格进化档案（知道你讨厌什么、喜欢什么）
    ↓
Phase 1: 创作者挖掘意图（最多4问/轮，基于历史偏好精问）
    ↓
Phase 1.5: 自动联网调研 + 更新知识库
    ↓
Phase 2: 匹配模板 → 制定规则（含历史偏好注入）
    ↓
Phase 3: 执行者产出 ≥2版初稿
    ↓
Phase 4: 读者以人类视角评审 → 选出最佳
    ↓
Phase 5: 呈现给你 → 你的指正即时记忆
    ↓
Phase 5.5: 进化分析师自动提炼 → 更新风格档案 🧬
```

| 随笔/散文 | 微观切入 → 延展联想 → 内在冲突 → 留白结尾 |

| 商业文案 | 痛点 → 放大痛苦 → 方案 → 信任背书 → 行动 |
| 小说/故事 | 破局点 → 升级 → 高潮 → 余波 |
| 🆕 社交媒体短文 | 标题hook → 人设锚点 → 分点分享 → 标签互动 |
| 🆕 视频脚本/口播稿 | 0-3秒hook → 价值承诺 → 递进观点 → 行动号召 |

## 🛡️ AI 痕迹检测

内置完善的 AI 痕迹避坑指南，涵盖：
- **词汇警戒线**：40+ 中英文高危 AI 词汇
- **结构性模式**：对仗强迫症、结尾升华综合征、破折号滥用
- **内容空洞信号**：端水大师、时间遁词、模糊归因
- **v2.1 新增**：Reader 评审时优先检查用户历史禁忌
